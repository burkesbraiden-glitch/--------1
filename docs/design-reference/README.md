# 设计参考图

本目录用于保存童旅记最终效果图。设计图是界面视觉实现的最高优先级标准。

固定映射如下：

| 文件名 | 页面 |
| --- | --- |
| 01-home.png | 首页 |
| 02-plan.png | 探索计划 |
| 03-guide.png | 讲解卡 |
| 04-task-list.png | 观察任务 |
| 05-task-detail.png | 任务详情 |
| 06-record.png | 最终探索相册手账版记录页面 |
| 07-profile.png | 我的，已登录资料页 |
| 08-login.png | 登录 / 未登录引导页 |

06-record.png 必须对应探索相册、拍立得照片、胶带、贴纸、儿童手账版本。
