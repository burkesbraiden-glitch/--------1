# 童旅记 Design System v2

## 设计原则

童旅记是克制、可信赖的亲子文化旅行学习 App。画面以温暖纸张感承接旅行与学习，而不是把每一段内容包装成贴纸手账或作品集。信息优先于装饰：一次阅读只突出一个主要行动，内容按层级自然展开，留白用于理解而非堆放卡片。

## 色彩

| 角色 | Token | 色值 / 用途 |
| --- | --- | --- |
| 页面背景 | `tl-bg` | `#F8EFD9`，米黄色纸张底色 |
| 主要文字 | `tl-text-main` | `#4A2F1B`，标题和正文 |
| 主行动 | `tl-primary` | `#F26A21`，当前步骤或唯一主 CTA |
| 温和信息面 | `tl-surface` | 基于纸张色的普通承载面 |
| 辅助信息面 | `tl-surface-muted` | 次级信息、轻量筛选或输入区 |
| 清爽辅助色 | `tl-blue` | `#CFE7F5`，仅用于有语义的提示、照片或插画背景 |
| 分割 | `tl-divider` | 低对比细线，不用粗阴影划分层级 |

橙色只承担关键状态和主行动；浅蓝、浅绿不用于制造无意义的卡片分类。

## 排版

| 层级 | Token | 规范 |
| --- | --- | --- |
| 页面标题 | `tl-type-page-title` | 44–48rpx，700 |
| 分区标题 | `tl-type-section-title` | 32–34rpx，600/700 |
| 正文 | `tl-type-body` | 28–30rpx，400，行高 1.55–1.7 |
| 元信息 | `tl-type-meta` | 24–26rpx，400 |
| 主按钮 | `tl-type-primary-action` | 28–30rpx，600 |

新系统不使用 `900` 字重。旧页面可维持既有局部样式，本次不以全局样式强制覆盖它们。

## 间距

横向页面留白默认约 32rpx。使用语义间距而非随意填数：`xs` 16rpx、`sm` 24rpx、`md` 32rpx、`lg` 48rpx、`xl` 64rpx。标题、正文、图片区块之间优先用留白和分割线建立节奏。

## 圆角

`small` 为 12rpx，适用于小标签；`control` 为 20rpx，适用于按钮与输入；`media` 为 24rpx，适用于照片与插画；`sheet` 为 32rpx，适用于底部抽屉。既有 `radius-lg`、`radius-md`、`radius-sm` 是兼容 token，不作为新页面的优先选择。

## 阴影

普通文字和列表不加阴影，普通媒体也应无阴影或只使用极轻阴影。只有底部 sheet、遮罩层等浮层才使用清晰的 `shadow-overlay`。既有 `shadow-card` 仅为旧页面兼容保留，不能成为默认卡片样式。

## 照片与插画

照片和插画服务于地点、观察任务与孩子的发现；用明确的画面、简洁的媒体圆角和必要说明承载信息。水彩质感可以保留在真实内容与少数引导场景中，但不将胶带、印章、星星、树叶作为普通内容的日常装饰。

## 按钮、列表、分割线与底部导航

主按钮使用 `tl-primary-button`，最小触达高度 88rpx；同一视图通常只保留一个主 CTA。次要动作使用低权重描边或文字形式，文字动作使用 `tl-text-action` 并维持同样的可触达面积，不做过度胶囊化。

列表默认是平面内容流：标题、正文、元信息和 `tl-divider` 即可表达层级。媒体或需要承载独立任务时才使用表面。底部导航维持五项业务入口和原有跳转逻辑，使用纸张背景、细分割线、橙色激活态与低权重棕色未激活态；SVG 图标保持统一尺寸与标签字重。

## 禁止项

- 禁止卡片套卡片，以及所有分区都做成卡片。
- 禁止无意义的英文 eyebrow；没有信息价值的标签不出现。
- 禁止把胶带、印章、星星、树叶当作普通内容装饰。
- 禁止同屏多个主 CTA；主行动必须清楚。
- 禁止静态 Demo 内容冒充动态内容。没有真实状态或数据时，应明确显示占位、空状态或示例性质。
