# 童旅记产品说明

## 项目名称

童旅记

## 目标用户

带 3-12 岁孩子旅行的家庭。

首版重点：7-12 岁。

## 核心问题

孩子旅行时只是跟着走和拍照，缺少观察、思考、表达和成长。

## 产品定位

童旅记不是普通旅游推荐平台，而是亲子旅行学习 App。

它帮助家长在旅行前、旅行中和旅行后，引导孩子完成观察、发现、提问、表达和成长记录。

## 核心流程

创建探索计划
→
查看讲解卡
→
完成观察任务
→
记录照片和发现
→
形成探索相册
→
沉淀成长记录

## 核心功能

1. 探索计划
2. 儿童友好讲解
3. 亲子提问
4. 观察任务
5. 任务完成记录
6. 照片和文字发现
7. 探索相册
8. 成长收获
9. 登录和孩子档案
